# Solution: 35_20_p14 — Fair Shares

**Answer: 10 values: 3, 4, 7, 8, 11, 12, 15, 16, 19, 20**

## Step-by-Step Solution

### Step 1 – Find the necessary condition
The sum of the numbers from 1 to n is **n(n + 1) ÷ 2**. To split the set into two equal-sum subsets, this total must be even.

Thus n(n + 1) must be divisible by **4**. Among two consecutive numbers, this happens exactly when **n is 0 or 3 modulo 4**.

### Step 2 – List the values up to 21
The values from 1 to 21 that are 0 or 3 modulo 4 are:

**3, 4, 7, 8, 11, 12, 15, 16, 19, 20.**

### Step 3 – Confirm the condition is sufficient
For every n with n ≡ 0 or 3 (mod 4), the set {1, …, n} can indeed be split into equal sums. For example, n = 8 gives the split in the question: {1, 2, 3, 4, 8} and {5, 6, 7} both sum to 18.

So there are **10** possible values of n.
