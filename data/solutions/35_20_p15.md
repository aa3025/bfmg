# Solution: 35_20_p15 — The Robot

**Answer: 2262 cm**

## Step-by-Step Solution

### Step 1 – Find how many straight runs are completed
The successive run lengths are 1, 2, 3, and so on. After 64 runs, the total number of steps is:

**1 + 2 + ··· + 64 = 64 × 65 ÷ 2 = 2080.**

So the robot finishes exactly at the end of the 64th run.

### Step 2 – Combine each group of four runs
Each group has moves east, north, west, south. In the first group the net displacement is (-2, -2) grid steps; the same is true for every group of four, because the west run is two steps longer than the east run and the south run is two steps longer than the north run.

There are **64 ÷ 4 = 16** groups, so the final displacement is:

**(-32, -32)** grid steps.

### Step 3 – Calculate the distance
The straight-line distance is therefore **32√2** grid steps. Every step is 50 cm, hence:

**32√2 × 50 = 1600√2 cm ≈ 1600 × 1.414 = 2262.4 cm.**

Rounded to the nearest centimetre, the answer is **2262 cm**.
