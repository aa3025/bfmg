# Solution: 35_20_p3 — Chambers in the Labyrinth

**Answer: 6**

## Step-by-Step Solution

### Step 1 – Understand the structure
The labyrinth is a **4-row × 6-column** grid. Each cell contains coins based on its row:
- Row 1 (top): **1 coin** per cell
- Row 2: **2 coins** per cell
- Row 3: **3 coins** per cell
- Row 4 (bottom): **4 coins** per cell

You enter top-left and exit bottom-right, moving **only right or down**. Every path visits exactly **9 cells** (5 right moves + 3 down moves).

### Step 2 – Set up the coin formula
Suppose a path spends *a*, *b*, *c*, *d* cells in rows 1, 2, 3, 4 respectively.

Two equations hold:
- **Total cells:** a + b + c + d = 9
- **Total coins:** 1a + 2b + 3c + 4d = 21

Subtracting the first from the second: **b + 2c + 3d = 12**

Also the grid has 6 columns, so a + b + c + d must use all 6 columns meaning (a−1) + b + c + (d−1) = 5, which gives a + b + c + d − 2 = 5... Wait — because each row-segment's *right moves* stack up to 5 total. This naturally constrains which combinations fit the 6-column grid.

### Step 3 – Enumerate valid paths systematically
Working through all valid (a, b, c, d) combinations that fit inside the 6-column grid and sum to 21 coins, we find exactly **6 paths**:

| Path | Coin sequence | Description |
|------|--------------|-------------|
| 1 | 1, 2,2,2,2,2, 3,3, 4 | Down at col 1, col 5, col 6 |
| 2 | 1,1, 2,2,2, 3,3,3, 4 | Down at col 2, col 4, col 6 |
| 3 | 1,1, 2,2,2,2, 3, 4,4 | Down at col 2, col 5, col 5 |
| 4 | 1,1,1, 2, 3,3,3,3, 4 | Down at col 3, col 3, col 6 |
| 5 | 1,1,1, 2,2, 3,3, 4,4 | Down at col 3, col 4, col 5 |
| 6 | 1,1,1,1, 2, 3, 4,4,4 | Down at col 4, col 4, col 4 |

Each path sums to exactly 21. ✓

### Step 4 – Verify no other paths exist
The minimum possible total is 1×6 + 2×1 + 3×1 + 4×1 = 15 (staying in row 1 as long as possible) and maximum is 1×1 + 2×1 + 3×1 + 4×6 = 30. A full systematic check confirms only these 6 paths reach exactly 21.
