# Solution: 40_30_p7 — Odd Addition

**Answer: 99**

## Step-by-Step Solution

### Step 1 – Look at the tens column
Let the star be S, the cross be C, and the circle be O. The addition is:

**SS + CC = 1SO.**

The result has a hundreds digit of 1, so the addition of the two tens digits must produce a carry into the hundreds column.

### Step 2 – Use the units carry
Adding the units digits S + C produces O and possibly a carry of 1 into the tens column. In the tens column we then have:

**S + C + carry = S + 10.**

Cancelling S gives **C + carry = 10**.

The carry can only be 0 or 1. It cannot be 0 because C would have to be 10, so the carry is 1 and:

**C = 9.**

Thus the requested two-digit number is **99**.
