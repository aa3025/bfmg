# Solution: 40_30_p16 — Lucien’s Paths

**Answer: 50 paths**

## Step-by-Step Solution

### Step 1 – Find the minimum possible number of arrows
Each angled arrow advances two grid units in one direction and one grid unit at right angles. Compare the total horizontal and vertical displacement from A to B with the displacement supplied by each arrow. This establishes the minimum number of arrows needed.

### Step 2 – Build only non-overlapping paths
Starting at A, place each left- or right-handed arrow in turn. Reject a partial path as soon as it leaves the grid, cannot reach B in the remaining arrows, or reuses a grid segment.

### Step 3 – Count the completions
The exhaustive search at this minimum arrow count produces **50** valid paths from A to B.
